高亮样式预览

半透明底色 + 同色系下划线 · 浅色/深色两套变量都已配好

行内荧光（mark.mk-*）

黄：可对角化的充要条件
绿：线性无关
蓝：基础解系
红：易错点
跨行效果：这一段的文字故意写得长一些，用来验证换行时每一行都各自带圆角和下划线，不会只画一条贯穿到底的长线

整块高亮（li.hl-* / p.hl-*）

  • 黄块：A 可对角化 ⟺ A 有 n 个线性无关的特征向量
  • 绿块：属于不同特征值的特征向量线性无关
  • 蓝块：r(A)=n−k，基础解系含 k 个向量
  • 红块：这条容易和「满秩」混淆

公式高亮（.katex.fml-hl-*）

A = P Λ P⁻¹　 |A − λE| = 0　 Ax = 0　 r(A) + r(B) ≤ n

批注框里的高亮（.ann-text mark）

这里的 半透明底色 配合下划线，和正文荧光是同一套观感；蓝色同理。

题库 / 真题页的笔记高亮（mark.note-hl）

这条规则用在题目卡片里的笔记与批注上： 关键结论是这样高亮的， 绿色的推导步骤， 蓝色的补充说明， 红色的易错提醒。
