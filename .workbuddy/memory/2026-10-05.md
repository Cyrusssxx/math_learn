## 2021数一 16(9) 型题改用谱分解（xd_bank no=169，5d87656）
- 题目：A=(a,1,−1;1,a,−1;−1,−1,a)，(I) 求正交 P 使 PᵀAP 对角；(II) 求正定 C 使 C²=(a+3)E−A。
- **原解析缺口**：(I) 只给 P 的结果不说 P 怎么来（特征值/特征向量/为何正交化全缺）；
  (II) 只给 C 的结果不说 C 的来源。293/200 字 → 2550/434 字。
- **谱分解路线**：(I) 令 B=A−aE，|λE−B|=(λ−2)(λ+1)² → A 特征值 a+2、a−1、a−1；
  λ=2 取 (1,1,−1)ᵀ，λ=−1 解平面 x₁+x₂=x₃ 内正交化得 (−1,2,1)ᵀ。
  (II) T=(a+3)E−A=3E−B **与 A 共用特征向量**（T 是 A 的多项式），特征值减 3 得 1,4,4 全正；
  C=1·γ₁γ₁ᵀ+2γ₂γ₂ᵀ+2γ₃γ₃ᵀ = **2E−γ₁γ₁ᵀ**（只用到 γ₁ 一个投影，最省事）。
- **Node 精确验算**（a=2）：PᵀP=E；PᵀAP=diag(4,1,1)；C=(1/3)[[5,−1,1],[−1,5,1],[1,1,5]] 与谱分解逐元素一致；
  C²=T；顺序主子式 5/3, 8/3, 4 全正。KaTeX 77 段渲染失败 0。
- **踩坑**：特征向量 (1,1,−1) 我一度写成 (−1,−1,1)（差个负号）→ PᵀAP 变成 diag(4,1,4) 不是对角阵。
  **投影矩阵 γγᵀ 对符号不敏感，但 P 的列变了** —— 验证特征向量要「逐个候选跑 Av=λv」，
  别凭感觉写。定位这类问题最快的方法就是数值代入。
