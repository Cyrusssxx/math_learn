## 2019 Q13 答案补全为两法（commit 4022063，已 push）
- 用户：13 题答案要有两种方法——**分部积分和交换积分次序**，交换要注意积分域的上下限。
- 原答案只有交换法（217 字符）→ 重写为两法（970 字符）：
  - 方法一（分部积分）：$u=\int_1^x\frac{\sin t^2}{t}dt,\ dv=xdx$ → 边界项代入 0 → $-\frac12\int_0^1 x\sin x^2 dx$ 凑微分 → $\frac14(\cos1-1)$
  - 方法二（交换次序）：明确 $\int_1^x$ 在 $x<1$ 为**反向积分先化 $-\int_x^1$**；区域 $\{0\le x\le1,\ x\le t\le1\}$ 换序为 $\{0\le t\le1,\ 0\le x\le t\}$ → $-\frac12\int_0^1 t\sin t^2 dt$ 同得 $\frac14(\cos1-1)$
- 校验：$ 配平 0、控制字符 0、KaTeX 21 公式 0 失败；**sympy 复核两法结果一致** = (cos1-1)/4 ≈ -0.1149
