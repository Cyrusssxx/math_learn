## 拼卷「📋 LaTeX」复制按钮失效 —— 根因与修复
- **现象**：拼卷页部分题卡点复制按钮毫无反应（按钮文字不变、剪贴板不写）。
- **复现**：本地 127.0.0.1:8765 静态服务 + `agent-browser` 注入真实导出数据（`做题数据-2026-11-04 (1).json`，517 个键），`catSrcMode=core`；40 题卷里 6 题（15%）失效，失效 qid 全是真题卷题（`2017数二真题-4` 等）。对照题点击显示「已复制 ✓」。
- **根因**：`copyCatQLatex()` 只在 `allEntries`（当前 srcMode 单源，core 模式 1113 条）按 qid 找题，找不到就 `if (!hit) return` 静默退出；而拼卷 `ppRender()` 用 `ppOfQid()` 的 `_ppIdx`（examPapers + corePapers + bankItems 三源，2769 条）。**渲染源 ≠ 查询源** → 跨源的题必然查不到。
- **修复**（`pwa/js/category.js`）：新增 `catFindByQid(qid)` —— 拼卷/复测先走 `ppOfQid`（与页面渲染同源），分类页仍先 `allEntries`（保持原内容不变），最后 `allEntriesAllSources()` 兜底；找不到时 `catCopyFail()` 给按钮「未找到题源」提示，不再静默。`copyCatQLatex` 从 `q.source` 正则补 year，保证走 `_ppIdx` 拿到原始 core paper 时不丢「2004年 题1」前缀。
- **验证**：
  - `node --check pwa/js/category.js` 通过；
  - `tools/_test_pp_counter.js` **46 项全过**（新增场景 5 四项：反向验证旧实现查不到、拼卷能取到真题卷/核心题库题、不存在 qid 返回 null）；
  - 真机：6 道原失效题 + 1 道对照全部「已复制 ✓」；剪贴板 `2017年 题4\n微分方程 $y''-4y'+8y=...`（LaTeX 源码完整）；普通分类页 `PAPER_MODE=false` 复制正常，内容 `2004年 题1 ...`。
- **教训**：任何「按 qid 反查题目」的交互都要覆盖拼卷三源；查不到必须给可见反馈，静默 return 会被当成随机失效。

## 复现工具注意
- `agent-browser` 守护进程随 Bash 会话结束 → `open` / `eval` / `screenshot` 必须在**同一次 Bash 调用**里串起来，否则下一次是 `about:blank`。
- 输出必须重定向到文件，不要用管道（daemon 持有 stdout 会挂住 `tail`）；静态服务器用 `run_in_background` 常驻，普通后台 `&` 会随 Bash 结束被杀。
- vm 顶层 `let` 不在 `window` 上，但 `eval` 里可直接访问（如 `allEntries` / `_ppIdx` / `PAPER_MODE`）。
