## 解析风格标准（用户定稿，线代样例：2013 数值 15 题 A=uv^T 型）
**用户原话**：「别出现向量空间什么的东西；能用谱分解就谱分解（比较简单的话），我喜欢谱分解；然后再简单给一下谱分解之外的常规解法。」
1. **禁用抽象术语**：不写「向量空间 / 解空间 / 齐次解空间 / 张成 / 正交补 / 基」。
   改用具体说法：「$Ax=0$ 只有 $k_1\alpha+k_2\beta$ 这一族解」「$A$ 的每一行都同时垂直于…」「必然平行于…」。
2. **优先谱分解**：能从题中直接读出特征值/特征向量时（`$A\alpha=\lambda\alpha$ 可由通解的特解项与齐次项读出），
   用 $A=\sum\lambda_i\frac{v_iv_i^T}{v_iv_i^T}$ 写。**零特征值对应的投影矩阵显式说明「不用求」（乘 0 消失）**。
3. **再补一个常规解法**（简洁版），形成对照。
4. 结构：`【方法一·谱分解】`（①读特征值 ②谱分解 ③求幂）→ `【方法二·常规】` → `⚠️易错`。
5. **必配数值自检**：写完用 `mpmath`（矩阵）或 Python 精确整数运算验证结论。
   ⚠️ mpmath  dps=20 不足以判 `A^100 == 9^99·A`（9^99≈10^94 会误报 False）→ **大数幂必须用整数运算**。
6. 谱分解写法：`$A^n=\sum\lambda_i^n\frac{v_iv_i^T}{v_i^Tv_i}$`（各投影幂不变），比逐次相乘快且不易错。

## 矩阵高次幂解析模板（用户要求，产出 `矩阵高次幂解析模板.md`）
用户点名要的四类 + 补充一类，**每类给：识别特征 → 主解法(谱分解) → 备用常规解法 → 易错**，并要求「打序号」。
① 秩一型 $A=\alpha\beta^T$：唯一非零特征值 $\lambda=\beta^T\alpha$ ⇒ $A^n=\lambda^{n-1}A$；$\lambda=0$ 时幂零 $A^2=0$。
② 分块对角：$A^n=\mathrm{diag}(A_1^n,A_2^n)$；**必须真是分块对角**（上三角会串块，已验证会错）。
③ 相似对角化：$A^n=P\Lambda^nP^{-1}$；$P^{-1}\ne P^{T}$（除非实对称），已验证。
④ 实对称/二次型：$A^n=Q\Lambda^nQ^{T}$；$x^TA^nx=\sum\lambda_i^ny_i^2$，**必须正交变换**（保平方和，已验证）。
⑤ 幂零/周期：先算 $A^2$，多数高次幂题答案藏在 $A^2$ 里。
- **主公式（跨类型统一）**：$A^n=\sum_i\lambda_i^n\frac{v_iv_i^T}{v_i^Tv_i}$（各投影幂不变），零特征值项**显式说明不用求**。
- 已用 mpmath 逐条验证；**踩坑**：`mp.matrix.diag()` 只接受 2 个参数，多块对角要自己拼零矩阵；
  `mp.almosteq` 不能直接比矩阵；`A^n=QΛ^nQ^T` 在含 √2 的矩阵上 `==` 会误报 False（误差 2.4e-58），**必须容差比较**。
