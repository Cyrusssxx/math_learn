## 分类页搜索归一化（category.html）

### 痛点
原 `catSearchMatch()` 只做 `toLowerCase().includes()`，且 `stem.replace(/\$[^$]*\$/g,' ')` 把公式**整块删成空格**：
- 带空格就搜不到（「极限 计算」整串匹配 → 0 结果）
- 全角字符/全角空格搜不到
- 公式内容全丢（搜 `sinx`/`int0x`/`x-t` 一律 0）

### 改法（pwa/js/category.js）
1. `normFont()`：全角 ASCII（U+FF01–FF5E）→ 半角、全角空格→空格、清零宽字符
2. `searchTokens()`：按空白切词，**AND 语义**（每个词都要命中）；token 内再去 `$ { } ^ _ & \` ` *`
3. `searchBlob()`：LaTeX **命令去反斜杠、结构符号当分隔、内容保留** ——
   `\sin x`→`sinx`、`\int_0^{x^2}`→`int0x2`、`\sqrt{x-t}`→`sqrtx-t`、`\frac{1}{2}`→`frac12`、`\begin{cases}` 整块删
4. `entrySearchBlob(e)`：每题算一次挂 `e._sb` 缓存（首轮 3.4k 条目 ~100ms，后续 1–2ms）
5. 搜索范围扩到 题干+答案+思路+易错(tips)+知识点路径+年份+题号+章节名
6. 统一入口 `setCatSearchKw()` —— 三处赋值点（`onCatSearch` / `selectCat` 退出搜索 / 恢复上次状态`st.search`）全部改走它，否则 `catSearchToks` 不同步（搜索永远 0 结果或永不过滤）

### 测试 tools/_test_cat_search.js（44 项）
- 从 category.js **按函数名抽取**源码再 `new Function('cats', ...)` 注入，不 eval 整文件（撞 DOM）
- ⚠️ 抽取器必须感知**正则字面量**：裸扫花括号会被 `.replace(/\{/`、`/\\begin\{[^}]*\}/` 里的 `}` 提前截断 → 写了个处理字符串/正则/注释的扫描器（正则判定看前一个有意义字符是否属于 `([{,;:=!&|?+-*%<>~^`）
- ⚠️ **反向验证踩到缓存**：变异测试必须用**新 entry 对象**，复用 A 段已算过 `_sb` 的对象会读到正常版 blob，导致「变异后仍然通过」的假象

- 真实题库命中：极限 400 / 「极限 计算」40 / sinx 166 / x-t 42 / int0x 103 / 变上限 15 / 洛必达 46

## 变限积分「含 x 换元」题源盘点（回答用户「有吗」）

判定口径：`\int` 的 **上限含 x**（先有 `_` 下限再有 `^` 上限，避免把 `e^{2x}` 的指数误当上限）**且被积函数里还有 x**（x 是参数不是积分变量）。

### 真题卷 5 道
| qid | 型 | 题干要点 |
|---|---|---|
| 2026数二-18 | **xt 型** | `∫_0^{x²} g(xt)dt` 求 f′ 及 x=0 连续性 |
| 2022数二-4 | **x−y−t 型** | `F(x,y)=∫_0^{x−y}(x−y−t)f(t)dt` 选性质 |
| 2018数二-16 | **x−t 型** | `∫_0^x f(t)dt + ∫_0^x t f(x−t)dt = ax²` 求 f |
| 2017数二-15 | **x−t 型（极限）** | `lim ∫_0^x e^t√(x−t)dt / √(x³)` |
| 2010数二-15 | **x²−t 型** | `f(x)=∫_1^{x²}(x²−t)e^{−t²}dt` 单调区间与极值 |

另有 **2015数二-11** `φ(x)=∫_0^{x²} x f(t)dt` 属「可提型」（情形 A，x 能提到积分号外），同章但不算换元。

### 核心题库独有 6 道（不与真题重复）
| qid | 型 | 题干要点 |
|---|---|---|
| core-102 | x²−t² 型 | `∫_0^x (x²−t²)f(t)dt`，F′ 与 x^k 同阶（1996 数一） |
| core-598 | x−t 型（两边） | `∫_0^x f(x−t)dt = ∫_0^x (x−t)f(t)dt + e^{−x}−1` 求 f（2016 数三） |
| core-618 | x−t 型 | `lim ∫_0^x t f(x−t)dt / (x∫_0^x f(x−t)dt)` |
| core-709 | t−x 型 | `x = ∫_0^x f(t)dt + ∫_0^x t f(t−x)dt` 求 f（1998 北京竞赛） |
| core-620 | t/x 缩放型 | `lim ∫_0^{2x} |1−t/x| sin t dt / x²` |
| core-633 | 上下限双含 x | `lim ∫_{−x}^{x} (1/x)(1−|t|/x)cos(θ−t)dt` 存在，求 θ |

### 与真题重复的核心题库题（不必重复刷）
`core-45`=2017-15、`core-148`=2026-18、`core-215`=2010-15、`core-415`=2022-4

### 排除项（扫描易误判）
- `2018数二-6` / `core-467`：二重积分 `∫dx∫(1−xy)dy`，不是变限积分
- `core-279`：`∫_2^x 1/(x(ln x)^{α+1})dx` —— 积分变量与上限同名，**原题印刷疑误**
- `core-619`：`∫_0^{φ(x)} f(t)dt`，被积只含 t → 属「换上限为函数」直接求导
- `ys27`：37 题里 **0 道**变限积分换元题

### 用法
搜索已支持公式，直接搜 `x-t`（19 题）/ `int0x`（60 题）/ `变上限`（8 题）即可捞出这类题。
