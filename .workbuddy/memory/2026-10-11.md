### 实现要点

**① 回顶 + 阅读进度环（合一个控件）**
- `index.html` 加 `.to-top`（SVG 环形进度绕在按钮外圈，`stroke-dashoffset` 驱动，
  不重排）；CSS 放在 🎨 左侧 `right:70px`。
- `updateToTop()`：滚过 320px 才出现（短笔记不闪烁）；百分比悬停时替代箭头显示。
- ⚠️ `scrollToTop` 供内联 onclick 调用，但 `new Function` 里的顶层 function
  **不挂 window** —— 测试要调它必须显式暴露（同一坑第二次踩）。

**② 搜索快捷键 `/` 和 Ctrl/Cmd+K**
- 全局 keydown 统一入口：**输入态（INPUT/TEXTAREA/contentEditable）全部让路**；
  Esc = 退出搜索/失焦；窄屏侧栏收起时先 `.show` 展开再 focus。

**③ 搜索命中正文标红（本次最复杂，3 个坑）**
- `markHitsInDoc(q)`：TreeWalker 遍历**文本节点**插 `<mark class="search-hit">`。
  三条硬约束：跳过 `.katex/.katex-display/annotation` 子树（插 mark 会让公式错位）；
  只切分文本节点不 replaceWith 元素（划词批注的内容锚点不受影响）；
  全部可撤销（`unwrapSearchHits()` + `parent.normalize()` 合并碎片）。
- **坑 1（时序）**：`locateHit()` 会先 `clearSearch()` 再异步 route→locateBlock，
  所以 locateBlock 里**不能读输入框**（已空）→ 关键词改为 `locateHit` 在 clearSearch
  **之前**捕获、塞进 `pendingLocate.kw` 随路传。
- **坑 2（语义）**：因此 `clearSearch()` **不能**撤销标红（会把刚标的清掉）——
  撤销职责移交给新函数 `exitSearch()`（Esc 走它）。
- **坑 3（提示载体）**：命中数提示最初挂在搜索结果框里 → locateHit 已把它 hidden，
  永远显示不出来。改成独立浮条 `#hitToast`（正文顶部居中，2.6s 自动消失）。
- 测试要求 KaTeX **真加载**（否则「标红不破坏公式」是空测，.katex 恒为 0）。
- ⚠️ 测试端到端链路必须**先模拟输入框打字**再 `doSearch(q)`：真实链路是
  oninput→doSearch(this.value)，直接调 doSearch 不写输入框 → kw 空 → 假失败。
- ⚠️ jsdom **不实现 `Element.scrollIntoView`/`scrollTo`**：locateBlock 会在标红前抛
  TypeError，表现为「标红 0」这种极难排查的假失败。必须给原型补桩。

**④ 宽表格接线 `.table-wrap`**
- 光套 overflow-x 容器**不够**：table 是 `width:100%` 永远等于容器宽，浏览器只会把
  8 列挤成一条、永远不触发滚动。正解 = `width: max-content; min-width: 100%`。
- 窄屏放开第一列 `white-space:nowrap`（它单独就能把表撑得极宽）。
- `reader.js` 与 `mdrender.js` 两份 emitTable 同步包 wrapper。

**⑤ 加载失败双栏交代**：docPane + navTree 都显示错误与「重新加载」按钮。

**⑥ 可达性**：`:focus-visible` 主色描边（按钮/链接/目录项），输入框补内阴影；
搜索框与 ☰ 补 aria-label。

### 顺带修掉一个全站缓存陷阱（重要，可复用）

**症状**：改完 advice.js、清了 SW 缓存并 reload，页面**还是旧文案**。
**根因**：`pwa/*.html` 里 20 处 `?v=f3eea060` 是**手写死**的 HTTP 缓存击穿参数，
构建脚本完全不管它 → SW 换了缓存，但浏览器 HTTP 缓存仍命中旧 JS。
（两层缓存的第二层被漏掉了。）
**修法**：新增 `tools/build_assets_ver.py` —— 按**被引用文件的内容哈希**（sha256 前 8 位）
自动填 `?v=`，并为原本裸引用的 cards/fav/good/selected* 5 个页面**补上**该参数（共 21 处）。
接进 `.githooks/pre-commit`，且**必须跑在 build_sw.py 之前**（sw.js 的 PRECACHE 含全部 8 个
html，先改 html 再算 CACHE_VER 才能如实反映）。
