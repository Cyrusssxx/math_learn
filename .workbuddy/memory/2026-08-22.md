### 关键发现：KaTeX 0.16 错误表现机制
- `.katex-error` 类检测对该版本**失明**——auto-render 默认 errorMode:'throw' + throwOnError:false 时行为复杂

- 灵敏度验证：注入 `\zzzunknown{x}` 到真实题干 → 完整管线检出 red=true ✅

## 关键 Bug 修复：精选页整页空白（本轮最重要发现）

用户再次要求「确保完全正确」，推动做**真实 HTTP + jsdom 端到端执行**测试，发现致命 bug：

- **现象**：精选页自 v1（07dcac0）起在真实浏览器中**整页空白**（永远"加载中…"）。
- **根因**：`pwa/js/selected.js` 第 172 行 `papers = await resp.json()` 把整个 `{papers:[...]}` 对象赋给 `papers`，而 `renderPaperList()` 调 `papers.map(...)` 期望数组 → 抛 `papers.map is not a function`，`init()` 中断。
- **为何之前漏掉**：所有前期校验都**绕过 init() 路径**（直接 data.papers 读、HTTP 只验资源 200、画廊只预渲染）——直到用 jsdom **真实注入 selected.html 脚本链 + mock fetch 跑 init()** 才暴露。
- **为何这次能发现**：HTTP 冒烟测试确认资源全 200 后仍不放心，加了 jsdom 端到端执行，直接触发 init→render→renderMath，第一步就崩。
- **修复**：`papers = (await resp.json()).papers || []`。
- **固化测试**：`tools/_accept_e2e.js`（jsdom 加载 common.js→katex→auto-render→selected.js，mock fetch 注入 selected.json，断言 16 题卡/116 KaTeX/112 答案图/31 套列表/0 残留$/0 错误 + 收藏·答案·过滤三交互 PASS）。
- **提交**：`0514b8c` 已 push。

### 方法论（重要，下次直接复用）
- PWA/前端验收**必须真实执行页面初始化链路**，不能只做组件级孤立校验——init() 路径的 bug 会被完全漏掉。
- KaTeX 0.16 + auto-render(throwOnError:false) 的真实可见错误信号是 HTML 内 **`#cc0000`**（未知命令红色 mtext + 语法错 katex-error 均为红色），`.katex-error` 类检测对该版本不够、需结合残留 `$` 与 `#cc0000`。
- jsdom 用 `runScripts:"outside-only"` + 手动 `window.eval` 注入本地脚本，比 `resources:"usable"` 联网拉取可靠（Git Bash 环境无 localhost 服务）。
- curl 在 Git Bash 不可用 → 用 Python `urllib` 做 HTTP 冒烟。

## exam.json 真题卷 LaTeX 结构审计 + 修复（提交 533efe2，已推送）

背景：修复 2009 数二 Q10 的 `e^{|k||x|}`→`e^{k|x|}` 后，用户要求「检查还有没有类似错误，主要是真题卷」。

### 审计方法（静态结构校验，工具 `tools/_audit_latex.py` 可复用）
- 检查项：brace `{}` 平衡、`$` 奇偶（把 `$$` 当整块显示公式跳过，不计入行内奇偶）、`\left`/`\right` 配对、`\begin`/`\end` 配对。
- 两个关键**误报陷阱**已规避：
  1. `\frac12`、`\frac\pi4` 这类单字符分子是 KaTeX 合法写法 → 不能要求 `\frac` 后必跟 `{`，否则 160+ 误报。
  2. `\rightarrow`/`\leftrightarrow` 含 right/left 子串 → 正则必须要求 `\left`/`\right` 后紧跟分隔符字符 `[\.\(\)\[\]|<>{}\s]`，否则 7 个误报。
