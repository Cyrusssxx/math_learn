## 真题笔记空格消失 + H2 不生效修复（同 commit 50fc168）
- 用户反馈：笔记打空格和 H2 保存后不显示（颜色正常）。**此前未修**，本轮定位。
- **空格根因（离线实测 mdBlock，三处叠加）**：①`editorToNote` 把浏览器保真的 NBSP（\u00A0，contenteditable 用它保存前导/连续空格）**降级为普通空格**；②`mdBlock` 用 `raw.trim()`——**JS trim 视 NBSP 为空白**，行首 NBSP 一起删；③HTML 中连续普通空格折叠成 1 个。
- **修复**：editorToNote 只丢 `\u200B`（保留 NBSP）；mdBlock 改 `raw.replace(/^[ \t]+/,'').replace(/[ \t]+$/,'')`（只去普通空格/制表符）。**exam.js 与 exam-shared.js 的 mdBlock 两处同步**。实测 NBSP 前导/行内连续/纯 NBSP 行/行尾全部保留；旧数据普通行首空格行为不变（无回归）。
- **H2 根因**：`applyNoteFormat` 对 h1/h2 同样要求「必须选中文字」，光标停行内点击直接 return（只弹提示）→ 用户以为 H2 失效。修复：`needSel = cmd!=='plain' && cmd!=='h1' && cmd!=='h2'`。
- 已保存笔记中丢掉的空格**无法自动恢复**（存储层已丢），需重打。
