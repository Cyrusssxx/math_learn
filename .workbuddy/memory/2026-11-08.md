## 笔记主页高亮：黄色换淡杏黄 + 含公式下划线优化
- **需求**：用户「把高亮的颜色换一个，黄色的那个，笔记主页的」，在候选里选了「更淡的杏黄 `#ffe8b8`」；追加「下划线针对有公式的部分优化一下，看不清公式了，淡化还是怎么搞你来决定」。
- **范围**：`pwa/index.html` 笔记主页（`reader.js` + `annotate.js` + `notes.css`）。**未动**题库页 `NOTE_HLS` 与拼卷备注 `PP_NOTE_HLS` 的色板（仍是 `#fff3bf`），用户只指定了笔记主页。
- **换色**：`notes.css` 浅色主题六档同步降饱和（`--mk-y` `#ffe8b8`、`--mk-y2` `#ffe2ab`、`--hl-y` `#fff6e8`、`--hl-y-soft`、`--hl-y-block`、`--hl-y-line` `#e0a94f`），深色主题另配一套（`--mk-y` `#6b5c33` 等）；`.ab-y` 色点 `#ffd54a → #ffe8b8`；`annotate.js` 的 `ANN_HLS[0]` 与公式高亮色点 title 同步。标注按 `y` 键存储，改配色值即可让已有标注自动变色，**无需数据迁移**。
- **下划线优化（我定的方案）**：① 普通文字 `mark.mk` / `mark.note-hl` 的 `text-decoration` 由 `2px / offset 2px` 改为 **`1px / offset 3px`**（更细、更靠下）；② 含公式的 mark 用 `:has(.katex)` **整段取消下划线**，半高亮带从 52% 压到 30%（只贴最下沿），保住「被划过」的辨识度又不压分母 / 下标 / 积分下限。
  - ⚠️ 原理：CSS `text-decoration` 会传播进 inline 后代，KaTeX 子元素设 `text-decoration:none` **挡不住**，只能从父 mark 取消。`:has()` 不被支持时只是退回原样式，渐进增强、不会更差。
  - 批注编辑态 `annNoteToEditor` 是内联 style，CSS 覆盖不到，必须改 JS：`border-bottom:2px → 1px`、底色 `52% → 30%`。
- **验证**：`node --check` 通过；`_test_pp_counter.js` 51 项全过；真机 `--mk-y=#ffe8b8`、深色 `#6b5c33`、色点 `rgb(255,232,184)`；普通 mark = `underline / 1px / 3px / 52%`，含公式 mark 与 note-hl = **`line:none / 30%`**，3 个 KaTeX 公式正常渲染、无下划线横穿；截图确认淡杏黄不刺眼。
