## 【完成】修复 KaTeX 显示块公式被裁切（commit af7a8c3）
- 现象：公式上面显示不全（用户截图：偏导数定义 `\left.\dfrac{\partial f}{\partial x}\right|_{(0,0)}=...` 顶部被切）。
- 根因：`.katex-display` 有 `overflow-x: auto; overflow-y: hidden`（长公式横向滚动）但**垂直无留白**：
  - `exam.css`（真题页/分类页答案区）只有 `padding-bottom: 4px`，顶部 0
  - `notes.css` 的 `.katex-display` / `.ann-fml-d` 完全无 padding
- 修复：统一给上下留白（exam.css `padding: 12px 6px 10px`；notes.css `.katex-display` `12px 0 10px`、
  `.ann-fml-d` `10px 0 8px`）——对齐 good.css 里已验证可行的 `padding: 10px 6px 8px` 写法。
- **规律：凡 `.katex-display { overflow-x: auto }` 必须配 `overflow-y: hidden`（CSS 规定不能是 visible），
  因此必须给足垂直 padding，否则 KaTeX 字形微溢会被裁。**
- 核验：`tools/_check_katex_overflow.py`（KaTeX 渲染同款公式 → 读 vlist height/depth/负 margin）。
  结果 vlist 高 4.4em、baseline 下 1.175em、无负 margin 上溢 ⇒ 盒模型完整，裁切源确为顶部 0 padding。
- ⚠️ 本轮 `agent-browser open` 卡死 8 分钟（daemon 启动超时），未做真实浏览器截图验证；
  已改用 KaTeX 布局数据定量核验。下次浏览器验证前先确认 daemon 可用（`agent-browser close` 后重试）。
