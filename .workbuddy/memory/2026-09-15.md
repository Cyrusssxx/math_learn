## 真题笔记三连修（commit 2b050af + e74681c，已 push）
用户反馈：①空格保存后不显示 ②H2 大小不显示 ③插入图片后继续打字自动换行。
1. **图片后文字换行（新根因，已修）**：`.q-note-input .exam-note-img-wrap` 原为 `display:block`——block 元素在 contenteditable 段落内会被浏览器**拆段**，插入图片后光标落下一行。修复：编辑器内 wrap 改 `display:inline`（不拆段落，文字紧跟图片写入）；内部 `img/.exam-note-img-del` 仍 `display:none`（图片继续只在预览区显示）。预览区（.q-note-preview 内）保持 block 不变（图独占行）。
2. **行首空格丢失（补漏，已修）**：浏览器只把**连续空格**存为 NBSP；**单个行首空格是普通空格** → 渲染端 mdBlock 原逻辑删掉行首普通空格 → 缩进没了。修复：mdBlock 行首 `[ \t]+` 转为 NBSP 保留（`m.replace(/[ \t]/g,'\u00A0')`），**exam.js 与 exam-shared.js 两处同步**；行尾空格照旧去除。
3. **H2 大小**：9-14 已把 `.q-note-preview h2` 1.12em→**1.32em+左竖线**、h1→1.55em（commit 82bd35b）——用户看到的仍是旧效果 = **旧 SW 缓存**，强刷即可。
- ⚠️ bash heredoc 后续命令不受 python 失败影响（heredoc 结束后的换行命令独立执行）——本次 exam-shared.js 同步因文本不匹配静默跳过，靠第二次独立 Edit 补上。批量脚本改多处时每处都要回显确认。
