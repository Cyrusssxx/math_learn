**用户一句「那些重点题我不是都有吗」直接推翻了我的结论。** 我当时只在 `xd_bank.json` 自身 346 道里查重就断言"库内不缺"，实际上：

**教训（下次务必照做）**
1. **判重必须跨全部题库**：`xd_bank / core_bank / exam / bank_questions` 一起进候选池。只跟单一库比会得出"没有重复"的假结论。
2. **归一化不能把行内公式整体替换成占位符**。我第一版把 `$...$`→`Q`、`$$...$$`→`Q`，导致题干只剩十几个字，**短题干互相假匹配**（补01/补10 都匹配到同一道参数求导题，相似度 1.00）。正确做法：**只删 LaTeX 结构符号**（`\begin{}` `\left` `\` `$` `&` `{}^_^` 等），**保留公式内容里的字母数字**，再做 bigram Jaccard。
3. **阈值 + 人工双保险**：Jaccard ≥ 0.60 只作初筛，最终必须把「补充题题干 vs 库内题干」并排打印逐条核对。0.48~0.76 的 borderline 项（如补16、补39 因转写丢 `$E_n$` 的下标、丢矩阵行分隔符而打折）必须人工看，不能直接归为"新增"。
4. **`practice.json` 是死数据**：`grep -r "practice.json" pwa/` 零命中，任何代码都不加载它。里面的题对用户不可见，判重时要单独标记。

## core_bank 体检 → 发现并修复三库「一题多记录」缺陷（commit da5902a）

体检 `core_bank.json` 时顺带查出**三个库都有同一类系统性缺陷**：同一道题因挂到不同知识点（catId）被复制成多条**独立记录**，导致同屏重复出现、收藏/标记主键分裂成两条。

**判重方法**（沿用判重翻车复盘里修正后的归一化）：题干归一化（只删 LaTeX 结构符号、**保留公式内容**）+ bigram Jaccard，完全相同即同题；再区分
- **同卷内重复 = 异常**（同一份数据里同一道题出现两次）
- **跨卷重复 = 正常**（不同年份考同一题，如 2014数二真题-8 ≡ DG900JXB-212），保留

**修复规则**：每组保留 `answer` 最全的一条，其余条的 `categoryIds`/`deepCats` 合并进来后删除。这样分类树里各知识点仍可见，但只有一条记录。
