## 【紧急修复】记忆卡一打开就弹空「设置」框、整页点不动（61f0cf7）
- **现象**：用户报「记忆卡出来就弹个设置，点不了，也没有东西」——首帧就有一个标题为「设置」、

  所以 cards.html 里 `<div class="cd-modal" id="cdModal" hidden>` 的 `hidden` 属性**完全失效**。
  项目其它页面早已踩过并处理过（`exam.css:1083` / `category.css:135` / `notes.css:1082` 都有
  `.bg-panel[hidden] { display: none; }`），**记忆卡新页漏抄这一条**。
- **修复**：`cards.css` 补 `.cd-modal[hidden] { display: none; }`。
- **全站排查**：写 `_scan_hidden_conflict.js`（扫所有 html 的 hidden 元素 × 所有 css 的 display 声明，
  精确 token 匹配避免子串误报）→ **全站仅此 1 处冲突**；`bgPanel/bgUpload/searchResults/cdToast` 均无冲突。
- **测试盲区（重要教训）**：`_test_cards_v3.js` 之前**从未把 CSS 注入 jsdom**（外链 `<link>` 不会被加载），
  所以纯 CSS 类 bug 一律测不出。已改为把 `cards.css` 内联进 `<style>`，并补 6 条可见性断言
  （模态/列表/统计/提示条初始 `display:none`，打开设置 `flex` + 内容非空，关闭后 `none`）。
  **反向验证**：删掉修复那行 → 「设置模态初始不可见」「关闭设置后模态隐藏」两条立刻转红（`display=flex`）。
