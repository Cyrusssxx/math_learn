## 笔记字色在粗斜体上丢失修复（commit 54be97d 已推送，CACHE_VER=mathcards-d295f163bf）
- **根因（已浏览器复现）**：editorToNote/annEditorToNote 的 isBold/isItalic 分支只处理粗斜、不读取颜色。加粗后再上色时 Chrome 生成 `<span style="font-weight:bold;color:...">` 或 `<b style="color:...">`，序列化只走 isBold 分支 → 颜色整体丢弃（存成 `<b>文字</b>`）。这就是"很大概率染不上颜色"。
- **修复**：两端各抽 colorOf(ch,c,h)（style.color/backgroundColor + font color/bgcolor 兼容），isBold/isItalic 分支合并颜色上下文。exam.js + annotate.js 同步（annotate 同款 bug）。
- **渲染端还原验证**：mdBlock 对 `<c:#e03131><b>文字</b></c>` → `<span style="color:#e03131"><b>文字</b></span>` ✓，色/粗/高亮嵌套全正常。
- **手动保存实测正常**（输入→立即点顶部💾→localStorage 立即写入+收起）：用户感知"手动保存无效"是颜色丢失连带——存的值没颜色，预览无色，像没保存。颜色修复后消失。
- **图片四场景全验证不丢**：贴图+转正文(removeFormat)/转标题/上色/加粗 + 保存 + 重开，令牌保留、IDB 写入正常、预览回填成功（同步登记保护早前已加）。偶发丢图如再现需用户提供复现步骤。
- **测试坑**：①agent-browser eval 里 execCommand('bold') 返回 false（无真实焦点），不能用于格式复现——改为直接构造 Chrome 生成的 DOM 再验序列化；②服务器文件已改但 fetch 到旧内容 = 浏览器 HTTP 缓存，须 agent-browser close 重开（仅清 SW 不够）；③innerHTML 塞令牌字符串会被浏览器当未知标签解析，测 mdBlock 还原必须传字符串。
