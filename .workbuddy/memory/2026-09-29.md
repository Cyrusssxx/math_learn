- **⚠️ 关键工作流（下次照此做）**：
  1. 真题 PDF 直链：`https://cdn.jsdelivr.net/gh/swjtuhub/SWJTU-Courses@main/考研资料/数学/真题/...`（jsdelivr 比 raw.githubusercontent 稳；raw 大文件常 0 字节/超时，jsdelivr 对超大文件可能 503）。
  2. `pymupdf` 定位：`page.search_for(关键词)` 找题干；**真实绘图块要从 `page.get_bboxlog()` 里过滤 `'fill-text'/'stroke-text'`（注意是连字符，不是下划线）**，再按"宽高 > 20pt"筛出图形块（页面横线/下划线是 1px 高噪声）。
  3. **⚠️ rotation 坑**：扫描件常是 mediabox 竖版 + `/Rotate 90`。`set_rotation(0)` 后坐标与 mediabox 一致（文字竖排），但**渲染方向是转 90° 的**；要正常方向裁剪必须用**默认 rotation**（page.rect 为横版）并以"显示坐标"= (H_m - y_m, x_m) 换算。混用两套坐标是本轮反复裁空的主因。
  4. 矢量图 `page.get_drawings()` 只报顶层路径，**Form 内的要 `get_bboxlog()`**。
  5. 位图：`page.get_images(full=True)` + `fitz.Pixmap(doc, xref)` 直取像素（最清晰、无文字混入）。
  6. **每张图必须 Read 目视校验**（曲线形状/标注/刻度），确认与原题一致才挂。
  7. 挂载后：`core_bank.json` 紧凑单行写回 + `sw.js` PRECACHE 追加 + `tools/build_sw.py` 重算 CACHE_VER。
- **⚠️ 环境坑**：① managed python env **无 numpy**（pip 装 numpy 失败/超时）→ 用纯 pymupdf 方案，别依赖像素分析；② PowerShell **不支持 bash heredoc**（提交信息用 Write 写 `_commitmsg.txt` + `git commit -F`）；③ `Set-Content -Encoding UTF8` 会把中文/emoji 弄乱码 → 改文件用 Write 工具或 Python；④ PowerShell 变量后紧跟冒号要写 `${y}:`。
