## 实现方案：搜索后自动展开笔记并高亮相关章节

### 功能描述
当用户执行搜索后，左侧导航栏会自动：
1. 展开所有包含搜索结果的笔记文件
2. 高亮显示包含搜索结果的章节链接

### 具体实现步骤

#### 1. 修改 `reader.js` 文件

**步骤1.1：添加全局变量**
- 在文件开头添加 `let searchMatches = {};` 用于存储搜索结果映射
- 数据结构：`{ noteId: Set(chapterIndex1, chapterIndex2, ...) }`

**步骤1.2：修改 `doSearch` 函数（第336行后）**
- 从 `lastHits` 数组提取所有匹配的笔记ID和章节索引
- 使用 Set 去重，避免同一章节重复添加
- 自动展开包含搜索结果的笔记：`Object.keys(searchMatches).forEach(id => openFiles[id] = true);`
- 调用 `renderTree()` 重新渲染导航栏

**步骤1.3：修改 `renderTree` 函数（第249行）**
- 在生成章节链接时检查 `searchMatches[n.id]?.has(i)`
- 为匹配的章节添加 `search-match` CSS 类

**步骤1.4：修改 `doSearch` 函数的清空逻辑**
- 当搜索输入为空时，清空 `searchMatches` 并重新渲染导航栏

#### 2. 修改 `notes.css` 文件

**步骤2.1：添加搜索结果章节高亮样式（第275行后）**
```css
.tree-ch.search-match {
    color: var(--accent);
    font-weight: 600;
    background: var(--bg-active);
    border-left-color: var(--accent);
    border-radius: 0 6px 6px 0;
}
```

### 优点
- ✅ 实现简单，代码改动量小（约10行代码）
- ✅ 与现有架构完全兼容
- ✅ 用户体验流畅，搜索后立即看到导航栏更新
- ✅ 不影响现有功能（笔记展开、当前高亮等）

### 文件修改清单
- `pwa/js/reader.js`：添加搜索匹配逻辑和高亮支持
- `pwa/css/notes.css`：添加搜索结果章节样式
